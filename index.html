如何获得后续更新？

将 index.html 与 data.json 放在同一个网站目录。部署后网站每次打开以及打开期间每5分钟尝试读取最新 JSON。定时监测脚本只更新候选线索，管理员核对公告和附件后手动更新正式数据。

直接双击打开 HTML 也能使用内置快照；收藏保存在当前浏览器。本项目附带 GitHub Actions 定时监测配置，推送到仓库并启用 Pages 后方可运行。

核验与隐私

每条信息提供来源、发布时间、核验日期。高校专属公告会单独标注，报名截止有岗位差异时在详情页列明。

网页无需账号，搜索与收藏不上传服务器；不收集姓名、学号、身份证号等个人信息。下载日历只保存在你的设备中。

本站为非官方汇总原型，任何报考决定和资格确认均应以有关组织部门公告及职位表为准。
